# HTML & CSS Assignment 05 – Personal Portfolio Website

## 📌 About the Project

This project is a personal portfolio website created as part of **HTML & CSS Assignment 05**. It features a clean and modern layout designed to showcase a designer's introduction, skills, personal information, and portfolio projects.

## ✨ Features

- Navigation bar with menu links
- Hero section with introduction and contact button
- Skills section with circular percentage indicators
- About Me section highlighting personal attributes
- Portfolio section displaying project previews
- Social media icons and footer
- Clean layout with modern colors and styling

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Sections

1. **Home** – Introduction and welcome section
2. **Skills** – Displays design skills and proficiency levels
3. **About Me** – Highlights personal attributes
4. **Portfolio** – Showcases sample projects
5. **Footer** – Includes social media links and copyright information

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## 🎯 Purpose

The purpose of this assignment is to practice HTML structure, CSS styling, page layout, and the creation of a visually appealing portfolio website.
